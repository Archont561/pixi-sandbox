Pixi-sandbox is a pure Rust CLI with static musl binaries — no Python, no runtime deps.

## Via Cargo

<Tabs>
  <TabItem label="cargo install">
    ```bash
    cargo install pixi-sandbox
    pixi-sandbox --version
    # Now available as pixi extension:
    pixi sandbox --version
    ```
  </TabItem>
  <TabItem label="cargo from git">
    ```bash
    cargo install --git https://github.com/Archont561/pixi-sandbox pixi-sandbox
    ```
  </TabItem>
</Tabs>

## Via Pixi Global (canonical)

Connected hosts need Pixi installed. The supported installation path is the native package from the pixi-sandbox channel:

```bash
pixi global install --channel https://prefix.dev/archont561/pixi-sandbox --channel conda-forge pixi-sandbox
pixi-sandbox init
```

The package-specific channel installs this CLI. `pixi-sandbox init` separately configures the Archont561 namespace root for project dependencies.

## Via Release Binary (transport bootstrap)

Standalone binaries and `SHA256SUMS` remain available for verified transport bootstrap. Download the
matching binary and checksum file, verify it with your platform's SHA-256 tool, then mark it
executable. Connected hosts should use the canonical Pixi package above.

### Asset contract

Each release publishes:

```text
pixi-sandbox-x86_64-unknown-linux-musl
pixi-sandbox-aarch64-unknown-linux-musl
pixi-sandbox-x86_64-apple-darwin
pixi-sandbox-aarch64-apple-darwin
pixi-sandbox-x86_64-pc-windows-msvc.exe
SHA256SUMS
```

Default template `pixi-sandbox-{target}{exe}` — verified by setup action before exec.

## From Source

```bash
git clone https://github.com/Archont561/pixi-sandbox
cd pixi-sandbox
cargo build -p pixi-sandbox --release
./target/release/pixi-sandbox --version
```

## Verify Installation

```bash
pixi-sandbox tools list
# Shows embedded helper-tool pins (pixi, pixi-pack, pixi-unpack) per platform

pixi-sandbox --help
pixi sandbox --help  # via pixi extension
```
