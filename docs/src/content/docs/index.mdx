## What is pixi-sandbox?

`pixi-sandbox` packs one or more [pixi](https://pixi.sh) environments plus vendored Cargo crates into a directory, publishes it as an **orphan branch**, and restores it on a machine that cannot reach the internet.

<div style="display: flex; align-items: center; gap: 0.5rem; margin: 1rem 0; padding: 0.75rem 1rem; background: var(--sl-color-accent-low); border-radius: 0.5rem; border-left: 4px solid var(--sl-color-accent);">
  <Icon name="lucide:lightbulb" size={20} />
  <span><strong>Because pixi discovers <code>pixi-&lt;command&gt;</code> on PATH</strong>, installing pixi-sandbox unlocks native subcommands: <code>pixi sandbox pack</code>, <code>doctor</code>, <code>publish</code>, <code>restore</code>.</span>
</div>

## Quick Start

import { Tabs, TabItem } from '@astrojs/starlight/components';

<Tabs>
  <TabItem label="Connected">
    ```bash
    # Pack environments and vendor Cargo crates
    cargo build -p pixi-sandbox --release
    pixi sandbox pack \
      --repo-root . \
      --envs dev,docs \
      --output-dir .sandbox-transport \
      --platform linux-64 \
      --cargo-vendor \
      --fetch-tools \
      --self-bin target/release/pixi-sandbox

    # Verify
    pixi sandbox doctor --branch-location .sandbox-transport --verify

    # Publish
    pixi sandbox publish \
      --input-dir .sandbox-transport \
      --branch-name sandbox/linux-64
    ```
  </TabItem>
  <TabItem label="Airlock">
    ```bash
    # Fetch
    git fetch origin sandbox/linux-64:sandbox/linux-64

    # One-liner offline reconstruction (PATH aliases wired like setup-pixi)
    bash scripts/restore.sh sandbox/linux-64
    # or: pixi run sandbox-restore

    # Manual restore
    .pixi-sandbox/tools/linux-64/pixi-sandbox restore \
      --branch-location /tmp/sb \
      --output-path .

    # Prove offline
    source .pixi/sandbox-env.sh
    pixi install --frozen --offline
    cargo build --offline
    ```
  </TabItem>
  <TabItem label="GitHub Actions">
    ```yaml
    # .github/workflows/publish-sandbox.yml in your project
    jobs:
      sandbox:
        uses: Archont561/pixi-sandbox/.github/workflows/publish-sandbox.yml@v0.2.0
        with:
          config: .pixi-sandbox.toml
          release-version: v0.2.0
        secrets:
          SANDBOX_PUSH_TOKEN: ${{ secrets.GITHUB_TOKEN }}

    # Or short refs
    - uses: Archont561/pixi-sandbox/setup@v0.2.0
      id: setup
      with:
        version: v0.2.0
    - uses: Archont561/pixi-sandbox/publish@v0.2.0
      with:
        project: .
        environments: dev
        platform: linux-64
        branch: sandbox/linux-64
        self-bin: ${{ steps.setup.outputs.path }}
        remote: https://github.com/OWNER/REPO.git
        output-dir: /tmp/transport
    ```
  </TabItem>
</Tabs>
