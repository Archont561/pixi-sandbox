## What is pixi-sandbox?

`pixi-sandbox` packs one or more [pixi](https://pixi.sh) environments plus vendored Cargo crates into a directory, publishes it as an **orphan branch**, and restores it on a machine that cannot reach the internet.

  <Icon aria-hidden="true" name="lucide:lightbulb" size={20} />
  <span><strong>Because pixi discovers <code>pixi-&lt;command&gt;</code> on PATH</strong>, installing pixi-sandbox unlocks native subcommands: <code>pixi sandbox pack</code>, <code>doctor</code>, <code>publish</code>, <code>restore</code>.</span>

## Quick Start

<ContextChips chips={["connected", "network"]} />

```bash
pixi global install --channel https://prefix.dev/archont561/archont561 --channel conda-forge pixi-sandbox
pixi-sandbox init
```

Commit the generated configuration, restore launcher, and project-owned publishing workflow. The
workflow calls the installed CLI directly on native runners; composite Actions and the repository
reusable publisher have been retired from new refs.
