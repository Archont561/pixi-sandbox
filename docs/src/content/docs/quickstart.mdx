## On the airlock

An extracted orphan branch is self-contained. The root `pixi-sandbox` is a convenience copy of
the manifest-verified binary under `.pixi-sandbox/tools/<platform>/`; Git stores identical copies
as one blob. A bare invocation is deliberately read-only: it runs `doctor --verify` and prints
the next restore command.

```bash
cd /path/to/extracted-branch
./pixi-sandbox
./restore.sh /path/to/project
# equivalent explicit form:
./pixi-sandbox restore --branch-location . --output-path /path/to/project --force
```

Windows branches provide the matching `pixi-sandbox.exe` and `restore.ps1`.

## From CI: reviewed native matrix

<div style="display: flex; gap: 0.5rem; align-items: center; margin: 1rem 0;">
  <Icon name="lucide:settings" size={18} />
  <strong>Declare exactly what to publish</strong>
</div>

Don't infer every env from `pixi.toml` — projects have private test/bench envs.

```toml
# .pixi-sandbox.toml
schema = 1
branch_prefix = "sandbox"
cargo_vendor = true

[[bundle]]
name = "developer"
environments = ["dev", "docs"]
platforms = ["linux-64", "osx-arm64", "win-64"]
```

Validate locally:

```bash
pixi-sandbox plan --config .pixi-sandbox.toml
pixi-sandbox plan --config .pixi-sandbox.toml --json  # GitHub Actions matrix
```

The reusable workflow downloads checksum-verified standalone release, expands plan into one native job per bundle/platform, packs, verifies, force-pushes one branch per job.

<Tabs>
  <TabItem label="Reusable workflow">
    ```yaml
    # .github/workflows/publish-sandbox.yml in your project
    jobs:
      sandbox:
        uses: Archont561/pixi-sandbox/.github/workflows/publish-sandbox.yml@<sha>
        with:
          config: .pixi-sandbox.toml
          release-repository: Archont561/pixi-sandbox
          release-version: v0.2.0
        secrets:
          SANDBOX_PUSH_TOKEN: ${{ secrets.SANDBOX_PUSH_TOKEN }}
    ```
  </TabItem>
  <TabItem label="Short refs">
    ```yaml
    # Setup + publish via short refs (same repo)
    - uses: Archont561/pixi-sandbox/setup@v0.2.0
      id: setup
      with:
        version: v0.2.0
    - uses: Archont561/pixi-sandbox/publish@v0.2.0
      with:
        project: .
        environments: dev
        platform: linux-64
        branch: sandbox/dev-linux-64
        self-bin: ${{ steps.setup.outputs.path }}
        remote: https://github.com/OWNER/REPO.git
        output-dir: /tmp/transport
    ```
  </TabItem>
</Tabs>

## Direct actions (like setup-pixi)

Both live in same repo:

```yaml
# Setup
- uses: Archont561/pixi-sandbox@v0.2.0
  with:
    version: v0.2.0
- run: pixi-sandbox --version

# Explicit short paths
- uses: Archont561/pixi-sandbox/setup@v0.2.0
  id: setup
  with:
    version: v0.2.0
- uses: Archont561/pixi-sandbox/publish@v0.2.0
  with:
    project: .
    environments: dev
    platform: linux-64
    branch: sandbox/dev-linux-64
    self-bin: ${{ steps.setup.outputs.path }}
    remote: https://github.com/OWNER/REPO.git
    output-dir: /tmp/transport

# Long-form (pin SHA for supply-chain)
- uses: Archont561/pixi-sandbox/.github/actions/setup-pixi-sandbox@<sha>
- uses: Archont561/pixi-sandbox/.github/actions/publish-pixi-sandbox@<sha>
```

Verifies bytes against `SHA256SUMS` before making executable available on PATH. Generate checksums after native proof: `(cd release && sha256sum pixi-sandbox-* > SHA256SUMS)`. `latest` warns; pin in prod.

## Shipping the tool (.conda)

```bash
pixi publish --path crates/pixi-sandbox --build-dir .pixi/bld --target-dir dist
pixi publish --path crates/pixi-sandbox --build-dir .pixi/bld --target-channel file:///srv/channel
pixi global install -c file:///srv/channel -c conda-forge pixi-sandbox
pixi sandbox doctor --branch-location .sandbox-transport
```

Measured: 34s to build 594 KB package (1.26 MiB stripped binary), channel write produces `repodata.json` + `.zst` + sharded repodata — plain static host (Pages, S3) works as channel. Must combine with `-c conda-forge`.

## Sizes to expect

Measured small project (2 envs, 33 crates, linux-64):

| Part | Payload |
|------|------|
| conda envs (.conda channel) | 133 MB |
| cargo vendor tree (loose) | 33 MB |
| bundled tools (pixi, pixi-unpack, self) | 96 MB |
| **transport dir** | **262 MB** |
| **orphan branch after git dedup** | **~110 MB** |

Tools dominate small bundles — expected, git stores each tool blob once.
