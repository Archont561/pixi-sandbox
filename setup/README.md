# `setup` — short alias

Short reference alias for `setup-pixi-sandbox`. Use as:

```yaml
- uses: Archont561/pixi-sandbox/setup@v0.2.0
  with:
    version: v0.2.0
```

Implementation lives in `.github/actions/setup-pixi-sandbox/`. Root `action.yml` is the same action, so `Archont561/pixi-sandbox@v0.2.0` also works (like `prefix-dev/setup-pixi`).
