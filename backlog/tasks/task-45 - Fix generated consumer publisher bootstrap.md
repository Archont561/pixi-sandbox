## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`pixi-sandbox init` 0.4.2 generates a consumer workflow that tries to build `pixi-sandbox` from the consumer checkout using the pixi-sandbox-only `package` environment and `build-release-binary` task. Replace that bootstrap with the released, SHA256-verified standalone binary so generated consumer publishers can reach pack on fresh repositories.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Issue #68 identified that every consumer generated by 0.4.2 fails before `pack` because `pixi run -e package build-release-binary` exists only in pixi-sandbox's own repository. Replaced source builds with release-asset downloads for the four Unix targets and Windows, verified against the release's `SHA256SUMS`, and updated the generated-workflow regression to reject source-build assumptions. AC#4 awaits the GitHub CI result after the implementation commit.
<!-- SECTION:NOTES:END -->
